# MP2: Data Processing REST API

This project is a FastAPI application that exposes the MP1 data cleaning pipeline as a REST API. Clients upload a CSV file with `POST /upload`, which stores the data in memory and returns its ID, row count, and column names. `GET /datasets/{dataset_id}` returns up to `limit` rows along with the dataset's total row count, and `POST /datasets/{dataset_id}/process` accepts a JSON configuration that validates required and numeric columns, then removes duplicates, handles missing values, and optionally removes outliers using the reused MP1 modules in `data_pipeline/`, returning a cleaning report and replacing the stored dataset only when every step succeeds. `GET /health` reports the application status and version. Request middleware logs every request with a unique ID, HTTP method, path, status code, and duration, and returns the ID in an `X-Request-ID` header. Invalid input returns 400, missing datasets return 404, and malformed requests return 422. Tests in `tests/` use pytest and FastAPI's TestClient and can be run with `python -m pytest tests -v`; the server can be started with `python -m uvicorn main:app --reload`, with interactive documentation at `http://127.0.0.1:8000/docs`.
